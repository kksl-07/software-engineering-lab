# Software Engineering Lab

Hands-on learning repository for improving software engineering skills
through exercises and practical experiments.

## Learning Path

1. Data Structures
2. Complexity
3. Object-Oriented Programming
4. SOLID Principles
5. Testing
6. Design Patterns
7. HTTP
8. Concurrency
9. System Design

## Learning approach

Each topic follows:

Theory → Exercise → Review → Application to a real project

The real-world projects used alongside this lab are:

- PySpark ingestion library
- API ingestion
- PostgreSQL MCP server
